🔧 UTILITY / VCA / MIXING
Intellijel Amps x2 Intellijel Quad VCA Tiptop MISO Clank Toolbox Doepfer Dual S&H Precision Adder T-Networks 103 + 104 Cosmotronic Messor

Amps: Dual VCA with exponential response — use for CV and audio. Each has gain CV.
Quad VCA: 4 independent linear VCAs, mix output — ideal for 4-voice polyphonic gating.

Toolbox: Logic gates (AND/OR/XOR/NOT) + flip-flops + comparator.
Dual S&H: Sample & Hold x2 — gate-triggered random voltage source.
Precision Adder: V/oct summing — transpose/detune without pitch drift.

Messor: Compressor/limiter/sidechain — dynamics processing before Tascam.

OR: MIDI CC mode → CCs 1,74,71,7 → FH-2 → CV outs → Filter/FM/Slew/VCA control
USE CASE: Play Syntakt from modular performance pads, or live CC control of FH-2 CV destinations.
PRESET 4 — CLOCK MODULATION
PAD 1: Voltage mode → OUT1 → Tempi CLKMOD (manually speed up/slow down master clock)
PAD 2: Voltage mode → OUT2 → Trig Delay TIME CV (control flam intensity)
PAD 3: Gate mode → OUT3 → FHX-8GT PROB CV (touch to increase gate probability)
PAD 4: Gate hold → OUT4 → Maths CYCLE (hold to sustain repeating envelope burst)
USE CASE: Live clock and rhythm manipulation. Most expressive performance preset.

TASCAM MODEL 12 — MIDI CONTROL SURFACE MODE
The Tascam Model 12 can act as a MIDI control surface via USB. Use faders to control Syntakt mixer or DAW mixer. Also: set Tascam as MIDI clock slave to keep recording in sync with modular:
SYNC SETUP
• Tempi sends MIDI clock (DIN)
• DIN → FH-2 DIN → FH-2 MIDI thru → Tascam MIDI IN
• Tascam set to external sync
• Recording stays locked to modular tempo
FADER CONTROL
• Tascam USB MIDI → computer DAW
• Map Tascam faders to DAW mixer
• Use EQ controls to automate plugin params
• Tactile mixing of all 12 modular channels
USB AUDIO
• Tascam appears as 12-in/2-out USB audio
• Record all modular channels simultaneously
• Return tracks from DAW for processing
• Bounce to SD card independently
